# StockCausal

> 每天收盘后，把 A 股「**谁在买（龙虎榜席位）/ 杠杆在加还是减（两融）/ 谁在折价甩货（大宗）/ 钱流向哪个宽基（ETF 份额）**」落成本地 CSV，外加一个自选池日线库。
>
> 纯 Python 标准库，跑在本机，不依赖任何付费数据源。

做这个工具的目的只有一个：**让「我觉得这票会涨」变成「历史上这类情况，次日上涨的概率是多少」** —— 没有数据，所有判断都是印象。

---

## 它能给你什么

| 模块 | 内容 | 回答的问题 |
|---|---|---|
| 龙虎榜 | 个股上榜记录 + 买卖前 5 营业部席位 | 谁在买？机构、游资，还是散户大杂烩 |
| 两融 | 沪深北市场总量 + 个股融资余额/净买入 | 杠杆资金在加仓还是撤退 |
| 大宗交易 | 每笔成交价、溢价率、买卖方营业部 | 有没有人折价出货 |
| ETF 份额 | 沪深 ETF 每日总份额 | 钱在流向哪个宽基 |
| 日线库 | 自选池开高低收 + 后复权收盘 + 涨跌幅 | 用来算「如果当时这么做会怎样」 |

## 怎么用（全部在项目根目录执行）

```bat
:: 1) 每天收盘后抓当日数据（19:00 之后跑，收盘前当天数据是空的）
python scripts\main.py daily

:: 2) 更新自选池日线（默认保留最近 3 年）
python scripts\kline.py --watchlist

:: 3) 单独出 Excel（不联网，从 CSV 生成）
python scripts\main.py export

:: 4) 补漏：回补最近 30 个交易日
python scripts\main.py backfill --days 30

:: 5) 重新按规则生成研究样本池
python scripts\pick_watchlist.py
```

需要 Python 3.10+。除了**导出 Excel** 会自动装 `openpyxl`，其余全部用标准库。

产出：

```
data\*.csv                   事件数据（每张表都有「数据来源」列）
data\kline.db                日线库（SQLite）
out\每日数据_YYYYMMDD.xlsx    当日汇总，7 个 sheet
out\<代码>_日线.csv           单只行情导出
```

> 数据文件不入库（`.gitignore` 已排除）。clone 后第一次跑要联网。

## 数据从哪来（以及为什么混着取）

同花顺数据中心的服务端页面可以直接解析，但它有几个硬缺口，所以按「**谁的更全用谁的**」来取：

| 数据 | 主源 | 补全/回退 | 原因 |
|---|---|---|---|
| 龙虎榜 + 席位 | 同花顺 | 东财 | 同花顺一页就带买卖前 5 席位 |
| 两融市场总量 | 同花顺 | — | 只有最近 10 个交易日 |
| 两融个股 | 东财 | — | 同花顺只给余额前 50 名 |
| 大宗交易 | 东财 | — | 同花顺只给「最近 50 笔」，会跨日截断 |
| ETF 份额 | 上交所 + 深交所 | — | **同花顺没有这项数据** |
| 日线 | 同花顺 `d.10jqka.com.cn` | 东财 | 一次返回全历史，不需要 cookie |

每行都带 `数据来源` 字段，混源统计前先按它筛。

### 合规说明

- 全部是**公开网页/公开接口**，不需要登录，不涉及付费或私有数据。
- 请求有节流（同花顺 1.5 s/次；实测无限速连打会被 502），单次全量几十个请求。
- 仅供个人学习与研究，**不要用于商业分发**，不要高频请求。数据版权归原网站所有。

## 研究样本池怎么来的

`watchlist.txt` 里的 30 只不是「我觉得好的票」，而是 `scripts/pick_watchlist.py` 按机械规则选的，避免挑样本时带入偏好：

1. 上市满 3 年（否则凑不够 726 根 K 线）
2. 剔 ST/*ST（涨跌幅限制 5%/10% 不同，污染统计）
3. 剔北交所（涨跌幅 30%，另一个游戏）
4. 当日成交额 > 1 亿（保证测出来的收益买得进）
5. 按流通市值分 4 档，每档取流通市值最大的 N 只
6. 同一行业最多 2 只

> 想加自己的票直接往文件里加代码。**删之前记一笔删了哪只、为什么** —— 以后结论对不上时，这是第一个要回看的地方。

## 口径与已知限制

1. **涨跌幅是「复权后的真实收益」**，不是不复权价直接相减。除权日和行情软件显示的会有差异，我们这列才可用于回测（与东财后复权序列逐日比对，726 天误差 ≤0.01 个百分点）。
2. **股票只用不复权（seg=00）**，前复权对老股会变负数/被缩放，绝不混用；指数没有分红，用 seg=01 即原始值。
3. **停牌日没有 K 线**。算均线/收益率前先处理停牌，别直接 `shift(1)`。
4. **两融市场总量只有最近 10 个交易日**（上游页面只给这么多）。
5. **深交所 ETF 份额只有当日快照**，接口无日期参数；盘中或历史回补会跳过。
6. **收盘前跑会丢掉当天 K 线**（15:30 前当日 K 线没走完）。
7. **龙虎榜口径与同花顺略有差异**（同一天同花顺 86 行 vs 东财 95 行，多为北交所和特殊上榜）。
8. **不做全市场**，默认只做自选池；`python scripts\kline.py --all` 可以，约 2.7 小时。

### 防呆设计

- 取不到数据时**不会清空**已有数据（`REJECT_EMPTY`）
- 同日用更少行数覆盖旧数据会被拒绝（`REJECT_TRUNCATED`）
- CSV 先写临时文件再原子替换

## 常见问题

**Q：报 10061 连接拒绝？**
系统代理开着但代理软件没跑。程序会绕过系统代理直连，但如果代理是唯一出口还是会失败 —— 关掉系统代理或把代理软件开起来。

**Q：提示 `openpyxl` 装不上？**
没网或 pip 走不通。不影响数据，`data\*.csv` 用 Excel 直接打开即可。

**Q：同花顺改版了？**
原始页面会存在 `data\raw\`，对着改 `scripts\parse_ths.py` 里的正则。
